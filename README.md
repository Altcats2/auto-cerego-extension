# Auto cerego bot

A Chrome (MV3) extension that automatically answers cerego assignments.

# NOTE: This project is NOT intended to allow you to "cheat" your assignments in any way, shape, or form and should not be used in any setting where this behavior constitutes academic dishonestly. This project simply serves as an interesting exploration into how the technology behind the cerego system works and potential vulnerabilities within this system. Any use of this extension is your own responsibility and the provision of this repository does not constitute approval of any unauthorized uses. 

## Install

1. `chrome://extensions` → enable **Developer mode**
2. **Load unpacked** → select this folder
